# Elisa-Valeska-Rivera-Cruz-202205263
En este repositorio se desarrollarán las diferentes fases del juego "Pibbles vs las Piblas" donde estaré adjuntando el análisis del juego, diagrama de flujo y código del juego 
1. Análisis: En esta etapa fue desarrollada en clase junto con nuestra profesora la cual tuvo la idea de desarrollar un juego como proyecto final, esta fase me fue fácil ya que tome inspiración sobre algunos debates y se me hizo interesante saber quien de los dos grupos sabes más mediante preguntas rápidas y lógicas
2. Diagrama de Flujo: Esta etapa fue más complicada ya que tenía que seguir recolectando ideas para dicho proyecto y plasmarlas en un diagrama el cual no fue sencillo de realizar puesto que me llevo días en organizar dichas ideas y también desarrollar las nuevas, entonces para la realización de la imagen fue algo más fácil utilizando programas tales como Canva se me facilitó bastante
3. Código: Esta fase fue la más complicada puesto que tenía que utilizar las funciones del programa Python y no fue fácil desarrollar todo mi diagrama de flujo en líneas de código siendo que esta etapa me llevo demasiado tiempo en desarrollarla y al final me siento satisfecha con el resultado final, siendo un juego interactivo para varias personas siendo que cumple su objetivo con el que fue ideado en primer lugar.
